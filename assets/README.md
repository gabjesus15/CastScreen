# CastScreen Brand Assets

Este directorio contiene los recursos oficiales de identidad visual y logotipos de CastScreen:

- `icon.ico`: Icono oficial de Windows en múltiples resoluciones (16x16, 32x32) con compresión RGBA de 32 bits para instalador y accesos directos.
- `logo.png`: Logotipo isotipo oficial en alta resolución.
